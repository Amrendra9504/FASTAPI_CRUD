This project is just a CRUD operation where we are managing the student record.
Tech stack used:
    Frontend:
        HTML, CSS, JQUERY
    Backend:
        Python
    Framework:
        FASTAPI
    Database:
        MySQL

Steps need to run the project:
1 Clone the project
2 Create a virtual environment (python3 -m venv my_env)
3 Activate the virtual environment
4 Install the packages from requirements.txt file (pip install -r requirements.txt)
5 Go inside the source folder
6 run the project (uvicorn main:app --reload)
